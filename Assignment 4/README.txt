This is a website coded in HTML, CSS, and JavaScript that is a basic personal website for myself. 
This application is run by first download all the files, keeping them in the folders they are in and opening the index.html file.

If the files get mixed up while downloading, all the images go into a folder called images, all the JavaScript files goes in a folder named scripts, and the CSS file goes into a folder named styles.

I did not have time to reset the name for the home page, to reset the name I found that you can hit f12 to open the inspector, go to the application tab and click Local Storage. There you can click on the name and delete it to add a new name.
